# 🧊 方块工坊 · 3D 正方体组合与三视图

一个纯前端（Three.js + Canvas）的三维正方体组合工具，无需安装、无需联网，双击 `index.html` 即可使用。

## 功能

- **任意数量生成**：在左侧输入数量（1–200），点击「生成」，方块随机散落并自然堆叠。
- **拖拽组合**：默认「移动方块」模式，按住左键拖拽任意方块即可移动、堆叠；面贴面自动合并为一个「几何体」（组合）。
- **一键生成组合大立方体**：2×2×2 / 3×3×3 / 4×4×4 / 5×5×5，生成后自动选中。
- **整体旋转**：切到「整体旋转」模式，点击方块选中它所在的整个组合，按住左键拖拽即可绕组合中心旋转（水平拖=绕 Y 轴，垂直拖=绕 X 轴），松手自动吸附到 90°，保证方块仍对齐网格。
- **三视图**：勾选「主视图 / 俯视图 / 左视图」后，对应视图会从几何体表面缓慢剥离，最终平铺展示在屏幕下方（工程制图风格）。视图显示「当前选中的几何体」，未选中时显示全部方块；几何体变化时视图实时刷新。
- **辅助操作**：点击空白处取消选中；Delete 键或「删除选中」删除选中组合；「重置视角」恢复初始视角；右键拖拽平移、滚轮缩放。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 左键拖拽（移动模式） | 移动方块 |
| 左键拖拽（旋转模式） | 旋转选中的几何体 |
| 左键拖拽（空白处） | 旋转视角 |
| 右键拖拽 | 平移视角 |
| 滚轮 | 缩放 |
| 点击方块 | 选中整个组合 |
| Delete / Backspace | 删除选中组合 |
| 1 / 2 | 快速切换 移动 / 旋转 模式 |

## 文件结构

- `index.html` — 页面结构
- `css/style.css` — 样式
- `js/app.js` — 全部交互与三维逻辑
- `js/three.min.js` — Three.js r128（本地，离线可用）

## 运行方式

直接双击 `index.html`（推荐 Chrome / Edge / Firefox 最新版）；也可以用任意静态服务器托管整个文件夹。
